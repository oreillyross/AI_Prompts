# AI_Prompts

A collection of AI prompts for software engineering, architecture, design systems, interview prep, career planning, and privacy/compliance work.

## Prompt Library

### Root

- [Counter Argument](Counter_Argument.prompt) — Challenges a position with strong counterarguments, difficult questions, and assumptions that could undermine it.
- [ADR](ADR.prompt) — Architecture Decision Record generator for documenting important technical decisions, trade-offs, and context in a permanent repository record.
- [Adversarial Review Pattern](Adverserial_Review_Pattern.prompt) — A hostile-but-useful code reviewer that calls out bugs, security issues, and performance risks early.
- [Claude Design System](Claude.Design.System.prompt) — Design-system prompt for creating tokens, typography, spacing, shadows, and reusable component primitives from reference screenshots.
- [GDPR + Cookie Consent Retrofit](gdpr-cookie-retrofit-prompt.md) — Agent prompt to audit and retrofit an application for GDPR/ePrivacy-compliant consent flows, tracking policies, and user controls.
- [Grill Me](GrillMe.prompt) — A relentless planning and design challenge that forces a concept to be pressure-tested until dependencies and trade-offs are resolved.
- [I Teach You](ITeachYou.prompt) — A learning prompt that turns the AI into a patient teacher and explains a topic while guiding you through understanding it.
- [LeetCode Solution Walkthrough](Leet_code_solution.prompt) — Expert coding problem solver that gives a step-by-step breakdown, alternatives, pseudocode, implementation, and test cases.
- [PMARCA System](PMARCA_System.prompt) — High-intensity expert advisor designed to challenge assumptions, present counterarguments, and then support a stronger conclusion.
- [Research Career Path](research_study_Path_career.prompt) — Career analysis prompt comparing market demand, long-term outlook, and opportunities for React.js, Rust, and Machine Learning.
- [Review This Function](Review_This_Function.prompt) — Function review checklist focused on type hints, docstrings, error handling, validation, and hardcoded values.
- [Simulate Tough Interviews](Simulate_Tough_Interviews.prompt) — FullStack TypeScript interview simulator that asks behavioral and technical questions and gives feedback.
- [Style Generation](Style_Generation.prompt) — Generates detailed styling directions for a website, blog post, or README that can be handed to another agent.
- [Thoughts](thoughts) — Working notes on PRDs, testing, architecture, and workflow tools for software projects.
- [TypeScript Pro](typescript_pro.prompt) — TypeScript best-practices prompt covering modern syntax, import organization, lint expectations, and maintainable code patterns.
- [Verbalized Sampling](Verbalized_Sampling.prompt) — Prompt designed to improve diversity and creativity in AI responses by sampling multiple outputs from the full distribution.

### `coding/`

- [Navigation Links Spec](coding/navigation-spec.yml) — Navigation route-highlighting requirements, implementation tasks, and test scenarios for a sample application.

## Notes

This repository is a practical prompt library for using AI as a stronger collaborator in coding, design, analysis, and learning workflows.

Use each prompt by opening the file and pasting its contents into your preferred AI assistant or coding agent.
