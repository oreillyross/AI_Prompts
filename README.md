# AI_Prompts

A collection of AI prompts for various use cases including software engineering, career development, design systems, and interview preparation.

## Prompts

- **[ADR](ADR.prompt)** - Architecture Decision Record generator for documenting important technical decisions and their rationale in a structured format.

- **[Adverserial Review Pattern](Adverserial_Review_Pattern.prompt)** - Hostile code reviewer that identifies critical bugs, security vulnerabilities, and performance concerns that would manifest in production.

- **[Claude Design System](Claude.Design.System.prompt)** - Design system builder that creates comprehensive design tokens, typography scales, spacing systems, and component primitives from reference screenshots.

- **[LeetCode Solution Walkthrough](Leet_code_solution.prompt)** - Expert coding problem solver providing step-by-step walkthroughs, multiple approaches, pseudocode, and fully implemented solutions with complexity analysis.

- **[PMARCA System](PMARCA_System.prompt)** - World-class expert advisor that provides incisive, direct answers with strong counterarguments before supporting positions, inspired by Marc Andreessen's thinking style.

- **[Review This Function](Review_This_Function.prompt)** - Function code review checklist validator covering type hints, docstrings, exception handling, input validation, and hardcoded values.

- **[Simulate Tough Interviews](Simulate_Tough_Interviews.prompt)** - Realistic interview simulator for FullStack TypeScript engineers with behavioral and technical questions plus constructive feedback.

- **[Verbalized Sampling](Verbalized_Sampling.prompt)** - Technique for generating diverse AI responses by requesting multiple samples from the full distribution, achieving 2.1× more creative variation.

- **[Research Career Path](research_study_Path_career.prompt)** - Market analysis and career planning tool comparing demand, rates, and opportunities for React.js, Rust, and Machine Learning over 2024-2025 and beyond.

- **[TypeScript Pro](typescript_pro.prompt)** - Expert TypeScript development guide covering modern syntax, best practices, import organization, and strict linting rules for maintainable code.
